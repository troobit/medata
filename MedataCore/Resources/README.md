# MedataCore/Resources

Placeholder resource root. The resources `MedataCore` actually bundles live
**beside their owning modules** and are copied into `Bundle.module` by
`Package.swift`, not from this directory:

- `Sources/Pipeline/Resources/segmenter.mlpackage/` — Core ML segmenter
  (decision 27, task 23 output). Produced by `tools/segmenter/export.py` from a
  PyTorch checkpoint. Filename must match the `PipelineFactory` loader.
  **Gitignored** — built locally or by CI and bundled at build time.
- `Sources/Foods/Resources/cofid_db.sqlite` + `afcd_db.sqlite` — CoFID + AFCD
  food databases (decision 27, decision 39, task 74 output; IFCDB overlay
  removed). Generated by `tools/food_db/generate.py` and **committed** (the
  `.gitignore` un-ignores them explicitly).
