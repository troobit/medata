# Swift Package layout

The repo root holds both the legacy SvelteKit MVP (to be moved to `legacy/` at task 70)
and the new Swift Package for the iOS-first carbohydrate-estimation pipeline. They
coexist while Foundation is being built; the Swift sources live in `MedataCore/` and
`HarnessCLI/`.

## Topology

- `Package.swift` (root) — single SwiftPM manifest declaring `MedataCore` library
  + `HarnessCLI` macOS executable + per-target test bundles. Platforms: `iOS 17`,
  `macOS 14`. Swift tools 5.9.
- `MedataCore/Sources/{module}/` — twelve modules per design §2.1: CaptureKit,
  CardDetection, SupportPlane, MetricScale, Segmentation, Volume, Foods, Macros,
  Confidence, Persistence, PortableContracts, Pipeline.
- `MedataCore/Sources/PortableContracts/Schemas/*.proto` — 27 canonical schemas
  (Decision 31). `Schemas/` is `exclude`'d from the SwiftPM target.
- `MedataCore/Sources/PortableContracts/Generated/*.pb.swift` — generated by
  `Schemas/generate.sh` (requires `protoc` + `protoc-gen-swift`); committed.
- `MedataCore/Sources/PortableContracts/{Vec3,Mat4,Projection}.swift` — Swift-ergonomic
  wrappers per design §3.1 with bridge initialisers to/from the `Pb*` generated types.
- `MedataCore/Sources/CaptureKit/SimdAdapter.swift` — only place `simd_float3` /
  `simd_float4x4` are bridged to portable Vec3/Mat4 (design §6.0 boundary rule).
- `MedataCore/Sources/CaptureKit/MetalContext.swift` — `@unchecked Sendable` per
  design §3.1.1; falls back to an empty in-memory library when no bundled metallib.
- `App/` — placeholder dir for the iOS app target; the Xcode project is created
  interactively at task 53.

## Generated protobuf naming

`option swift_prefix = "Pb"` in every .proto produces names like `PbVec3`, `PbMat4`,
`PbCameraIntrinsics`, `PbMealRecord` (no underscore). The `--swift_opt=Visibility=Public`
flag is required so other targets can depend on `PortableContracts`.

To regenerate after editing a .proto:

```sh
bash MedataCore/Sources/PortableContracts/Schemas/generate.sh
```

## Build / test

```sh
swift build       # builds all module targets + HarnessCLI
swift test        # runs PortableContractsTests, CaptureKitTests, SegmentationTests
```

The `MetalContextTests` skip gracefully when `MTLCreateSystemDefaultDevice()` returns
nil (e.g. headless CI without a GPU).
